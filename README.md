# 🌸 Dulhan Saree Collection – Business Website

A fully frontend website for **Dulhan Saree Collection**, a saree shop in **Govandi, Mumbai**. It helps customers discover the latest collections and get the shop's information in one place.

🔗 **Live Demo:** https://deft-druid-394999.netlify.app/

## ✨ Features

- Elegant hero section with a premium maroon and gold theme
- **Collections** showcase: Bridal, Banarasi, Silk, Paithani and Wedding sarees
- **New arrivals** section so customers can see the latest designs
- **Shop timings** (opening and closing hours)
- **Contact details:** phone number, email and Instagram link
- Floating **WhatsApp** button for quick enquiries
- Smooth navigation: Home, Collections, About Us, Instagram, Contact
- Responsive layout for mobile, tablet and desktop

## 🛠️ Tech Stack

- **HTML5**: structure
- **CSS3**: styling and layout
- **JavaScript**: interactivity
- **Netlify**: hosting and deployment
