# Dulhan-Saree-Collection
Responsive business website for Dulhan Saree Collection, a saree shop in Govandi, Mumbai. Showcases Bridal, Banarasi, Silk &amp; Paithani collections, new arrivals, shop timings and contact details (phone, email, Instagram), with a WhatsApp enquiry button. Built with HTML, CSS &amp; JavaScript. Live on Netlify.
